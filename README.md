# VioletNix

**Stories from the past. Lessons for today.**

Short history tales, each about a minute long, with a lesson at the end, for TikTok, YouTube Shorts,
Instagram Reels and Pinterest.

## Download

⬇️ **[Download all videos (ZIP)](https://github.com/thelilactester-cloud/VioletNix/archive/refs/heads/main.zip)**

Each day has its own folder. Every video has a caption file with the same name, with text and
hashtags for TikTok, YouTube, Instagram and Pinterest. `schedule.csv` is the posting checklist.

## About the videos

- Vertical 1080×1920 and just over 1 minute long. A calm narrator tells a true story from history,
  ending with a lesson.
- Background photos: free for commercial use (CC0 / Unsplash / Pexels licences), from the
  open-source wallpaper collections of elementary OS, Pop!_OS and Cassidy James.
- Narration: [Kokoro](https://github.com/thewh1teagle/kokoro-onnx), an open-source AI voice
  (Apache 2.0). Tick the "AI-generated" label when posting.
